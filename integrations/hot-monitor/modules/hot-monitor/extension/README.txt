测写收集 v2.4.0（Chrome／Edge）

更新或安装
1. 解压网站下载的 hot-monitor-collector.zip。
2. 打开 chrome://extensions（Edge 为 edge://extensions）。
3. 已安装：在原插件卡片点击重新加载；首次安装：开启开发者模式，加载含 manifest.json 的 hot-monitor-collector 文件夹。
4. 刷新测写网页和准备收集的原帖。旧版已展开的大浮窗可直接关闭；新版不会自动展开。

手动收集
1. 保持 http://127.0.0.1:43110 或 http://localhost:43110 的测写网页打开，不需要先选选题。
2. 在具体帖子、文章或视频页面点击浏览器工具栏中的插件，展开小面板。
3. 选择「收集素材」或「收集案例」。选择所属文章，默认沿用最近操作的测写网页所选文章；也可以明确选择全局库。
4. 收集素材：原帖来源保存到测写，后台下载该帖能取得的图片／视频；在素材库查看进度、失败原因和处理版本。
5. 收集案例：进入测试案例库的“待筛选”区，再下载分析、核对原帖提示词／复现提示词、匹配已有案例，确认后入库。
6. 同一帖子可以分别用于素材和案例，来源与相同文件复用。不会自动把他人演示当作本机实测。

AI 搜索 X（与手动收集分开）
1. 使用平时已登录 X 的 Chrome，打开一个 X 标签页，点击插件。
2. 在小面板点击「将此 X 标签供 AI 使用」，再到“寻找素材与案例”页或写作设置的「X 搜索与素材」连接 Chrome 采集。
3. 保持测写网页打开。可直接在写作助手说要找什么图片、案例或视频；AI 搜索和选择，后台下载并处理，媒体归入本篇及素材库。
4. 此模式会在明确选定的 X 标签中导航，不要同时使用该标签做其他浏览。在写作设置随时断开。
5. 原帖截图只包含 Chrome 实际可见区域。长帖标明截断；Mac 锁屏或窗口无法捕获时截图失败，原文和媒体可继续处理。

范围
只连接本机 43110 端口。手动收集只读取当前明确点击的页面；不导出 Cookie、不读取密码、不要求调试或全站权限。公开网页是否能取得视频取决于原帖可访问性；删除、验证或不可下载的媒体如实报错。不会要求自动化窗口重新登录 X。插件不代替网站 Agent 授权或同事知识库服务。

2.2 更新
支持收集素材、收集案例、收集并解析。目标可以选择公共库或文章，支持重点标记。
网站的自动搜集浮层、案例解析面板会记住解析 Agent 与模型。未配置时只保存案例，去网站选择模型后解析。
收集并解析会选择当前 X 标签并连接本机桥接；状态可在插件中查看，关闭插件不停止后台任务。
视频解析需实际读取关键帧，未公开的提示词只能形成复现草稿；确认后才进入可测试案例。
更新本地文件后需在 Chrome 扩展管理页重载并刷新原帖；无需重新登录 X。

2.3.0 效果采集
在测写的实测结果中点击“打开效果”，进入真实生成网页后点击浏览器工具栏的测写插件。
小窗口提供截图和录制；录制需选择目标标签页或窗口。操作网页后点“停止并保存”，素材自动保存到打开它的测试结果，并继承该结果的文章关联。
截图要求原效果标签在原窗口处于显示状态。保存期间保持测写网页打开，勿关闭采集窗口。
在“效果与素材”点开视频，可截取片段、裁剪画面、压缩为 MP4 或转 GIF。处理版本与原件放在同一组，原文件保留。
录屏上限约 95 MB，达到后停止并保存；单个上传视频最大 100 MB。浏览器采集不调用 Agent，不读取其他标签页内容，不增加 Cookie 或全站权限。

2.4.0 统一连接
连接入口统一到测写左下角“连接与设置”。首次点击连接 Chrome 采集时授权 X 网站访问；插件选择已有 X 标签，没有则打开 X。登录仍由用户完成。授权后保留配对，重启可恢复，不读取或导出 Cookie。断开会清除持久配对。
新版本需要在扩展管理页重载一次。可选 X 访问不等于网站已登录，登录过期或验证码仍需手动处理。
