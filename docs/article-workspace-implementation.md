## 运行规则

- 公共库内容只保存一份。article-resource 表示每篇的待筛选／选用／忽略／移除与重点状态；既有引用快照继续保留。选择文章不会移动或复制原文件。
- 当前文章是导航上下文；后台任务另存自己的 articleId、模型、数量、需求与请求键。任务启动后不追随当前页面。
- 自动搜集通过本机已授权 Agent 使用网站限定的搜索、读取和保存工具。第一次以 X 为目标，其他平台仍保留已有外链能力。搜索结果只是线索；必须真实读取后才能入库。
- 默认只保存原帖信息和可取得预览，不批量下载完整视频。用户选定后再下载／整理提示词。搜集不直接改正文，不自动确认正式案例。
- 同一 X 标签串行处理命令。网站重启后旧任务明确中断，可继续；插件可复用此前明确选定的标签恢复连接，不导出 Cookie。
- 自动演示的具体执行边界沿用 media-workflow 文档。程序录制和编码；演示 Agent 仅在用户明确选择后观察和操作现有页面，不向产物补写旋转等功能。
- 本轮增加画面百分比裁剪，保留原件与衍生关系；相关媒体按结果实例优先分组，避免旧的本地结果 URL 造成跨结果混组。
