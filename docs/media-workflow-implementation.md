# 案例采集、自动演示与写作素材

2026-10-29。本轮只更新本地网站。保留选题筛选、已有 X 跳转与手动采集，信源覆盖核对交给队友。不使用 SocialData 或所谓 DeepSeek Search 付费接口。

## 功能与入口

| 入口 | 操作与保存 |
| --- | --- |
| 已收集线索详情 → 下载并分析 | 读取 X 原文、下载图片／视频、抽取真实关键帧；模型整理可编辑的复现提示词，展示相似本地案例，人确认后进入正式案例库 |
| 结果详情 → 整理素材 → 生成演示 | 程序打开原始 HTML、滚动或拖动、录屏、编码 MP4／GIF，生成封面；新测试完成时自动提交一次，不修改原始文件、评测状态或模型耗时 |
| 同处 → 演示助手 | 选择已接入 Agent／模型并输入展示要求。Agent 通过截图判断，调用有上限的点击、按键、滚动、拖动工具；程序执行并录制真实动作 |
| 写作设置 → X 搜索与素材 | 连接已登录 Chrome 的一个明确授权 X 标签。AI 自主拟关键词、读帖子、挑选素材，不要求用户先提供链接 |
| 写作助手 | 通过共用工具搜索 X、读公开网页、截原帖、下载视频、看关键帧、截片转 GIF；真实媒体以本地文件地址进入 Markdown，后端转成文稿媒体节点 |
| 正文 → 插入媒体 | 默认本篇，按原帖或测试结果分组，保留原视频与衍生 GIF 关系；也可全局搜索、上传或沿用拖放 |

## 录制分工与边界

程序使用 Playwright 操作独立产物浏览器，使用 FFmpeg 记录和编码。普通下滑不需要 LLM。拖动视角只用于本来就有三维画布和视角交互的产物，画布没有变化时会提示失败。静态图片不能变出背面，缺失的旋转功能不会被补写。

复杂演示由 Agent 观察截图，再选择程序提供的有限动作。不能执行任意脚本或改文件；最多 12 步。编码裁掉模型等待时间，保留实际操作片段。可重新给要求再生成一版；原产物和已生成素材保留。游戏目前只支持已有点击、方向键／WASD 等有限操作，不承诺任意游戏自动通关或选出最佳片段。

任务保留进度、错误和取消；服务重启后的未完成任务标记为中断，不冒充完成。录制失败不改变原评测结果。

## Chrome 采集连接

1. 更新 `integrations/hot-monitor/modules/hot-monitor/extension` 为 v1.2。网站下载包同时包含旧手动采集与新桥接文件。
2. 在平时已登录的 x.com 标签点击采集插件一次，明确授权这个标签。
3. 在网站写作设置点击连接 Chrome 采集，保持至少一个本机网站标签页打开。
4. Agent 的搜索／读取请求进入本机队列，插件只在选定 X 标签中执行。截图短暂激活该标签后恢复原标签。
5. 截图为原帖实际可见区域，长帖有截断说明；Mac 必须解锁。窗口不可捕获时继续读原文和媒体，单独返回截图限制。

不导出 Chrome Cookie，不读取密码，不请求 debugger、cookies 或 all_urls 权限。插件仅把明确操作的公开帖子资料传回本机。网站与插件使用短时本机会话密钥配对，密钥不进入页面状态消息或模型提示词。不要同时手动使用这个 X 标签浏览别的内容。

X 视频先采用本轮 Chrome 页面确认的该帖视频播放列表，排除音频轨和孤立初始化片段；下载与 GIF 转换仍由程序完成。没有页面视频线索时才尝试公开帖子提取。不可访问、已删、受验证阻断或没有视频的帖子如实报错，不绕过验证。

## 共用工具与执行器

`media-tool-session.ts` 提供按文章／任务划分的能力会话，`scripts/media-tools.mjs` 是薄的 MCP stdio 桥接。搜索、浏览器读取、下载和编码都在网站后端执行。模型不直接读写本机文件。

- GPT 通过 app-server 的动态工具接到同一会话。
- WorkBuddy 通过严格 MCP 配置接入，普通文本评测继续关闭这些工具。
- DeepSeek Harness、MiniMax 通过 ACP 的 MCP 配置接入。
- API 配置通过函数调用循环接入同一工具集合。

四个本机执行器已实际调用工具验收。适配器可以传递工具，不代表每个型号都支持图像；反推视频提示词须真正读取关键帧，未读取时不会通过分析校验。关键帧均匀覆盖视频，并包含实际时间点。原文中逐字可核对的提示词与复现提示词分开保存，不假装恢复隐藏提示词。

写作先取得真实知识库上下文并校验引用。正文缺失或格式／引用不合格时只补交一次；仍不合格则失败，不能显示正文已更新。已保存文稿、媒体锚点、人工并发修改和历史版本保护保留。

## 本机依赖

仓库已固定 Playwright 版本。新机器安装项目依赖后运行 `pnpm setup:media`，准备项目内 yt-dlp Python 环境和 Playwright 的视频编码辅助程序；FFmpeg 主程序沿用 ffmpeg-static。可用 `CASEBENCH_PYTHON`、`CASEBENCH_YTDLP`、`CASEBENCH_BROWSER_PATH` 指定现有程序。下载程序来自官方包仓库，不需要新增搜索 API 密钥。

`.casebench`、tools 中的运行环境、私有工具会话文件及 output 下的验收产物均不进入公共仓库。正式业务数据、现有 Agent 授权和同事的知识库令牌不迁移到测试目录之外。
