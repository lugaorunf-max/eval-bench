原可测试通过 `CaseLibrary` 渲染，备选／回收站另建 `editorial library-manager` 页面，额外叠加 20px 内边距且状态栏上下边距不同。1280px 实测搜索框向右移 20px，状态栏向右移 20px、向上移 10px。此前验收未比较状态切换的坐标。

## 提示词反推的实际行为

收集链接进入备选。用户在备选详情选择 Agent／模型并点击“下载并分析”后，程序读取原帖、下载可得图片和视频，模型通过受限工具读取真实图像或按时间抽取的视频帧，再生成复现提示词、原帖逐字可核对的提示词、依据、未知项及相似案例候选。视频存在但模型没有读帧时拒绝保存分析结果；不能把重建结果冒充隐藏的原始提示词，也不保证一次复现同样效果。

分析结果自动保存为草稿，仍留在备选；点击确认保存才成为可测试案例，亦可关联已有案例。不会自动开跑测试。
