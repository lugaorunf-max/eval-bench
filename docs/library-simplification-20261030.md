## 已实现

1. 新测试默认 `timeoutSeconds: null`，表示不限时。高级设置可主动设置时限，支持超过一小时；切换页面不停止后台任务。已开始的旧任务不擅自修改参数。执行器实际异常退出会结束相关任务并保存已收到的输出、耗时和用量，不能因长时间无输出就伪报超时。
2. 执行记录展示提示词、逐轮公开回复、工具活动、耗时、Token 和最后活动时间。只展示执行器实际公开返回的推理摘要，不请求或编造内部思考链。HTML 交付没有单独正文时，保留执行器实际回复作为会话记录。文件和错误信息按需展开。
3. 公共案例、素材和实测集合默认全部，不读取最近编辑文章作为隐式限定。移除公共库的常驻文章列表，使用固定宽度的“关联文章”筛选。文章工作台仍限定本篇；测试可独立运行，也可明确关联文章。颜色文章标签来自真实关系，与普通分类标签分开。
4. 案例卡片保留名称、短摘要、任务类型、产物、考察能力、来源和文章关系。原帖全文在详情查看。AI 轻量整理新线索，分类可人工修改；没有材料的旧记录保持待分类，不批量猜测。封面按手动指定、视频有效帧、原帖图片、占位排列。视频抽取多个候选帧，排除明显黑屏，可换帧或上传封面；封面帧不作为独立正文素材充斥素材库。
5. 结果详情收为“效果与素材 / 执行记录”。默认不再自动生成演示视频。打开生成网页时使用独立本机来源，仅提供该结果的文件。查看效果后由人决定展示操作，通过插件或网页截图、录屏、上传；程序负责截取、画面裁剪、压缩 MP4 和转 GIF。自动演示仅留在高级操作中。
6. 原视频和处理版本归组，打开具体素材后处理、下载或加入文章。录制和处理继承原结果的文章关系，独立测试不会猜测文章。正文插入仍由明确位置确认，不把案例提示词直接塞进正文。
7. 上下调节改为细分隔边框，扩大不可见的命中区，悬停显示拖动状态；双击恢复默认，键盘和尺寸持久保存继续可用。
