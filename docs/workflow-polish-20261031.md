## 变更

- 所有写作执行器共用的 editorial policy 直接要求 Markdown 一句一自然段、段间空行，保留标题、列表、引用、图注和代码块。没有增加交付后拆句处理，也不自动重写旧文章。
- 沿用任务、能力、产物字典，案例新增可选 scenes / artifactTypes 数组。旧 scene / artifactType 仍是主要执行字段，旧数据按其单项读取。保存、解析草稿、人工编辑、筛选及卡片支持多项，执行快照不受后续修改影响。
- 已有案例可使用 AI 补全标签，只读提示词和要求，返回建议及依据，不执行测试、不自动发布。采用建议到表单后由用户保存新版本。水力案例现存标签确为 code / coding / web，不是前端隐藏其他标签。
- 封面卡片、详情、编辑使用相同的手选／视频帧／来源图规则，参考输入另存。编辑可看当前封面、换帧、上传及恢复自动封面，换图按钮不提交整个案例表单。
- AI 搜索支持持久交流历史、追加要求、切换执行器继续、固定目标和已有链接去重。关闭只隐藏记录；历史可重新打开，错误在面板内折叠。完成后停止高频刷新。
- 插件连接只在左下角连接与设置；移除其他连接面板及分析按钮。统一 AI 搜索命名，案例库移除收集链接。插件 2.4.0 首次请求现有声明的可选 X 权限后寻找或打开标签，显式配对可持久保存，断开则清除。无需导出 Cookie。重载扩展后，旧网站标签必须刷新一次。
- 素材页按案例页的搜索、状态、数量和排序工具行排列，消除额外缩进。历史下载信息收进浮层，不把卡片挤下去。
- 列表不再抽视频帧，抽帧仍由下载后处理及显式换帧入口触发；关系读取按请求批量复用，不能跨修改缓存旧文章关系。浏览器列表请求短期去重并在修改或库事件时失效，图片懒加载，只在解析执行中轮询资料。
