## 数据与运行

可分享的提示词、视频、封面和清单保存在 `data/case-library/kimi-2026-10/`，随代码进入 Git。完整会话、登录凭据、业务数据库与导入前备份保留在忽略目录中。

导入通过 `scripts/import-case-bundle.ts` 调用网站已有服务，正式写入在单个数据库事务内执行。PGlite 导入时先停止网站；所有文件先核验校验值和路径，再完整备份业务目录，导入完关闭数据库并恢复原生产预览。信源服务保持运行。

本机备份与证据位于忽略的 `output/kimi-import-20261031/`：

- `applied/database-before/`：停站后一致备份。
- `applied/result.json`：包内编号到本机案例／备选和素材的对应关系。
- `repeat-preview/plan.json`：再次导入预览为新增 0、复用 13。
- `verification.json`：提示词校验、视频 Range 播放、封面校验、旧数据比较。
- `bundle-tests.log`：数据包验证、去重与人工修改保护、备选边界、封面去重和非法文件防护测试。

真实飞书读取复用当前 Chrome 登录。批量下载时遇到 Chrome“下载多个文件”权限提示，确认后下载完成。机器人演示来自飞书实际链接的 `https://huali-car.cn/g1-atlas/`。没有导出浏览器 Cookie 或复用模型授权。
