你是一名资深 Three.js 创意开发者、动态视觉设计师和奢侈品网页设计师。

请创建一个名为“MIST.”的高奢香水交互式产品叙事网页，使用 Three.js + GSAP ScrollTrigger 或等效技术实现。

直接交付完整、可运行的单文件 HTML，CSS 和 JavaScript 内联，依赖通过 CDN 引入。不要只给代码片段或实现说明，不要使用静态截图或预渲染视频代替真正的实时 3D 场景。

一、整体视觉

- 使用暖白、象牙白和极淡香槟色背景，整体明亮、柔和、克制。
- 视觉风格参考高端香水广告和时尚杂志，不要科技感 HUD、霓虹灯、复杂卡片或厚重按钮。
- 画面中央是一瓶透明玻璃香水，内部为柔和蜜桃黄色或淡金色液体。
- 使用柔和摄影棚灯光、细腻边缘高光、真实玻璃反射与折射，以及非常淡的接地阴影。
- 页面排版采用“大号优雅手写英文＋小号高字距无衬线文字”的组合，保持大量留白。

二、香水模型

使用程序化三维几何体创建完整产品，不依赖外部模型或图片素材。

香水瓶必须拆分为独立部件：

1. 厚实透明玻璃外瓶，圆角矩形瓶身，带真实厚度和内部空间。
2. 独立的淡金色液体网格，液体与瓶内壁贴合。
3. 银色金属瓶盖、喷头、按压泵、装饰环和内部导管。
4. 独立瓶口和连接结构。
5. 正面白色纸质标签，使用 CanvasTexture 绘制“Mist”“PEACH HAZE”等文字。
6. 细腻但不过度的玻璃边缘高光和金属反射。

不能使用一个不可分割的整体网格代替所有零件，因为后续需要制作拆解、按压和微距镜头。

三、滚动叙事结构

使用固定全屏 WebGL 画布，HTML 文本覆盖在画布上方。页面滚动进度驱动一条连续、可逆的三维时间轴。

不要将页面做成普通的产品介绍卡片，也不要让每个章节显示一张不同的静态图片。

整个页面包含约 7 个滚动章节，推荐结构如下：

01 / 07 — INTRODUCTION
- 展示完整香水瓶，镜头为略带俯视的三分之四产品视角。
- 产品位于画面中部偏右，左侧或右侧出现大号手写标题。
- 瓶盖和喷头完整装配，产品带轻微浮动和环境反射变化。

02 / 07 — PRESS
- 镜头平滑推进至喷头顶部微距，突出金属喷头、喷嘴孔和按压结构。
- 显示手写文案“Scroll is a finger.”
- 随滚动让按压泵缓慢向下运动，随后回弹。
- 按压时从喷嘴产生细小、半透明的喷雾粒子，粒子向前扩散并逐渐消失。
- 喷雾必须是从喷嘴位置发射的粒子效果，不能只是全屏白色渐变。

03 / 07 — TOP
- 镜头沿瓶口向下移动，展示瓶盖、金属连接件、玻璃厚度和内部导管。
- 可让瓶盖轻微向上分离并悬浮，露出内部结构。
- 文案以极小号无衬线文字和少量手写标题呈现。

04 / 07 — HEART / PEONY
- 使用更具构图感的局部微距，展示金属、玻璃和液体之间的材质对比。
- 显示手写文案“Peony in slow motion.”
- 文字随滚动淡入、轻微位移，不要快速飞入或夸张弹跳。

05 / 07 — BASE / WOODS
- 镜头移动至瓶底和液体区域，展示玻璃厚度、折射和淡黄色液体。
- 产品可以在镜头前缓慢旋转少量角度，但不要变成自由旋转展示页。

06 / 07 — LABEL
- 镜头推进至瓶身正面标签，随后略微绕到侧面。
- 标签文字清晰，玻璃和液体不能遮挡文字。
- 镜头移动过程中要保持产品主体明确，避免无意义地切出画面。

07 / 07 — THE MIST
- 所有拆解部件重新装配。
- 镜头平滑拉远，回到完整香水产品构图。
- 左侧显示大号手写文案“Wear the Mist.”，完整产品位于右侧。
- 最终画面稳定、精致，可作为品牌宣传截图。

四、滚动与动画要求

- 使用 ScrollTrigger scrub 或等效机制，将滚动位置连续映射到相机位置、观察目标、产品旋转和部件位置。
- 向上、向下滚动都必须正确，支持反向播放整个产品叙事。
- 不使用硬切镜头，不在章节边界突然重置模型或相机。
- 使用阻尼、lerp 或平滑插值，让滚动停止后镜头自然缓冲。
- 微距与全景之间应通过连续相机运动完成。
- 页面静止时可以保留极轻微的反射变化和喷雾粒子，但不能让相机不停晃动。
- 鼠标移动只能添加非常轻微的视差，不能取代滚动叙事。

五、界面与功能

- 左上角为小字品牌标识“MIST.”，右上角为“PLAY”。
- 顶部和底部使用细线分隔，线条颜色为低对比灰褐色。
- 左下角显示当前章节，例如“02 / 07  PRESS”。
- 底部中央提供“TOP、HEART、BASE”香调导航，点击后平滑滚动到对应章节。
- 右下角提供“PÊCHE、COBALT、NUDE”三个颜色选项。
- 切换颜色时同步改变液体颜色、少量环境色和界面选中状态，不能只是改变按钮颜色。
- PLAY 可切换自动缓慢滚动与暂停；如果显示该按钮，就必须实现真实功能。
- 移动端保留完整叙事，但调整字号、相机距离和文字位置，避免遮挡产品。

六、验收标准

1. 页面滚动时，相机连续推进和拉远，而不是切换静态图片。
2. 反向滚动时，所有镜头和拆解动画能够正确倒退。
3. 喷头、瓶盖、导管和标签都是独立三维部件。
4. PRESS 章节确实包含按压动作和从喷嘴发射的喷雾粒子。
5. 最终章节重新展示完整装配的香水瓶。
6. 玻璃、液体、金属和纸质标签具有明显的材质差异。
7. 浏览器控制台无报错，桌面与移动端均可流畅运行。
