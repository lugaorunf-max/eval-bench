你是一名资深 Three.js 创意开发者和实时 3D 视觉设计师。请创建一个名为“Pink hour.”的交互式 3D 鸡尾酒网页。

请直接交付完整、可运行的单文件 HTML，CSS 和 JavaScript 内联，Three.js 及相关插件通过 CDN 引入。不要只提供代码片段、伪代码或实现说明，不要留下 TODO 和占位功能。

一、整体视觉

整体采用极简、高级、精致的杂志式视觉设计：

- 使用纯白或略带暖色的浅色背景，画面明亮、干净、留白充足。
- 页面中央展示一杯粉红色鸡尾酒，物体占据画面主要位置。
- 使用柔和的摄影棚灯光、细腻高光、环境反射和杯底淡淡的柔和阴影。
- 不要复杂房间、桌面纹理、深色背景或无关装饰。
- 整体效果应像高端饮品品牌的交互式产品展示，而不是卡通低多边形场景。

二、酒杯与装饰物

使用程序化三维几何体创建所有物体，不依赖外部模型或图片素材。

1. 酒杯

- 使用宽口、浅碟形的透明玻璃高脚杯，带细长杯梗和圆形底座。
- 推荐使用 LatheGeometry 构建杯身，确保玻璃具有真实厚度、杯口和内部空间，不能只是一个实心透明球体。
- 杯壁应光滑、优雅，轮廓连续，杯口略厚并有细腻高光。
- 使用 MeshPhysicalMaterial 表现玻璃，合理设置 transmission、thickness、roughness、ior 和透明效果。
- 玻璃要足够透明，能看清内部液体和冰块，同时保留可辨识的轮廓、反射与折射。

2. 液体

- 杯内装有明亮玫粉色、略带半透明质感的鸡尾酒。
- 液体与玻璃杯必须是相互独立的网格。
- 液体侧面和底部与杯身内部贴合，顶部具有独立、可动态变形的自由液面。
- 液面使用具有足够细分的 CircleGeometry、PlaneGeometry 或自定义网格，不能使用无法产生波浪的少量顶点网格。
- 液体需要有一定体积感，不能只是一张漂浮在杯口的粉色平面。

3. 冰块

- 杯内放置多块透明或半透明冰块，使用圆角立方体或轻微不规则的几何体。
- 冰块具有折射、反射、内部高光和边缘亮度。
- 冰块部分露出液面，排列自然，不要整齐堆叠。

4. 柠檬

- 杯沿装饰一片鲜黄色柠檬。
- 包含果皮、果肉、切面纹理和适当厚度。
- 柠檬固定在杯沿，不随液体漂浮。
- 可使用程序化 CanvasTexture 制作柠檬切面细节。

三、液体动态效果——核心要求

液体必须具有持续、自然、肉眼可见的动态效果，不能使用完全静态的液体网格。

1. 静止状态

- 即使用户完全不操作，液面也要持续产生细腻、轻微、连续的波浪和涟漪。
- 使用顶点着色器中的 time uniform，或逐帧更新液面顶点，实现多频正弦波叠加。
- 静止时的动画幅度应克制，但必须能够在录屏中辨认，不能微弱到完全看不见。
- 不能只旋转整个液体网格、移动整杯酒或改变材质透明度来冒充液体动画。

2. 拖动反馈

- 用户拖动观察酒杯时，将拖动速度、方向或相机角速度作为液体的视觉扰动输入。
- 拖动速度较快时，液面波动幅度适当增加，并产生轻微、自然的倾斜和晃动。
- 即使拖动控制的是 OrbitControls 相机，而不是酒杯刚体，也要将拖动速度用于液体扰动，保证交互反馈清晰可见。
- 不需要昂贵的真实流体模拟，优先实现稳定、流畅的视觉级液体晃动。

3. 停止与恢复

- 停止拖动后，液体不能突然静止，也不能永久保持最大幅度摆动。
- 使用弹簧阻尼、指数衰减或类似机制，让液面在数秒内逐渐恢复为静止状态下的微波动画。
- 波浪叠加和衰减过程必须连续，不能出现跳变、闪烁或液面突然重置。

4. 液体与冰块联动

- 冰块需要根据液面波动产生轻微的上下浮动、摇摆和缓慢漂移。
- 冰块的浮动应与液面运动大致协调，不要各自随机乱跳。
- 冰块始终留在液体和杯壁内部，不能穿出杯壁或明显飞离液面。
- 液面变形后仍需与杯壁自然衔接，不能出现明显缝隙、穿模、液体溢出或侧面断裂。
- 液面运动后需要正确更新法线，或在着色器中计算相应效果，保证高光和反射随波浪自然变化。

四、材质、灯光与渲染

- 使用 PBR 材质、ACESFilmicToneMapping 和合适的曝光设置。
- 使用环境光、柔光主光源和补光，让透明玻璃、粉色液体、冰块和柠檬具有清晰层次。
- 可使用 RoomEnvironment 或程序生成环境贴图增强玻璃反射，不依赖外部 HDR 文件。
- 添加柔和接地阴影，阴影不能过重或过于模糊。
- 可加入非常轻微的后期处理，但不要使用过度 Bloom，避免玻璃和液体细节被光晕吞没。
- 画面不能出现明显锯齿、严重闪烁或透明物体排序错误。

五、交互与镜头

- 默认视角为略带俯视的三分之四产品视角，可以同时看清液面、冰块、柠檬和杯梗。
- 使用 OrbitControls 或等效交互。
- 鼠标或单指拖动可围绕酒杯旋转观察，包括正面、侧面、俯视和接近正上方的视角。
- 支持滚轮缩放和移动端双指缩放。
- 缩放范围需要受限，避免进入杯子内部或远离到看不清物体。
- 相机带有平滑阻尼，不能生涩或突然跳转。
- 用户停止操作一段时间后，可以非常缓慢地自动旋转展示；再次操作时立即停止自动旋转。
- 自动旋转只负责观察展示，不能代替液体自身的动画。

六、页面 UI

页面只保留少量精致 UI：

- 使用优雅的小号衬线字体显示标题“Pink hour.”。
- 添加极简操作提示，例如“Drag to explore · Scroll to zoom”。
- 可加入细线条图标和少量玫粉色点缀。
- UI 不遮挡酒杯，不使用大型卡片、复杂导航栏或厚重按钮。
- 整体排版安静、高级，有充足留白。

七、性能与适配

- 桌面端和移动端均可运行。
- 根据设备像素比限制 renderer 的 pixel ratio，避免高分屏性能浪费。
- 窗口尺寸变化时，正确更新相机比例、渲染器尺寸和构图。
- 合理控制液面细分、冰块数量和阴影分辨率，优先保证动画流畅。
- 页面隐藏时可暂停不必要的渲染，恢复后动画不能突然跳跃。
- 打开 HTML 后即可运行，不需要构建工具或本地模型资源。

八、验收标准

完成后请自行检查以下要求：

1. 静置至少 5 秒，不操作鼠标，也能清楚看见液面微波和冰块轻微浮动。
2. 快速拖动时，液面波动和晃动幅度明显增强。
3. 停止拖动后，晃动自然衰减，不会突然停止或永久摆动。
4. 旋转到顶部、侧面和低角度时，液体均有完整体积，不出现空洞、穿模或杯壁接缝。
5. 柠檬稳定固定在杯沿，冰块不会穿出杯壁。
6. 缩放、旋转、窗口调整和移动端触摸均正常。
7. 浏览器控制台无报错，页面打开后立即可交互。
