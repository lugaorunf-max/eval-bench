## 导入本机网站

这是可重复导入的数据包，数据库与登录凭据不进入 Git。先停止 43110 本地网站，避免两个进程同时打开 PGlite；信源采集服务不需要停止。预览与正式导入分别运行：

```sh
pnpm exec tsx scripts/import-case-bundle.ts
pnpm exec tsx scripts/import-case-bundle.ts --apply
```

可用 `--bundle`、`--data-dir`、`--report-dir` 指定文件位置。正式导入前自动将当前业务目录完整备份到忽略的 `output/`，预览不改案例。导入完成后重新启动网站。

导入按包内编号和提示词校验值去重，保留已有标题、收藏、文章归属与运行历史。若已导入的提示词后来被人工修改，会停止并报告冲突。导入使用网站现有服务和事务；参考视频、封面、三类分类和集合同时建立，封面不作为独立素材卡重复出现。所有案例的额外 `instructions` 为空，任务类型可多选，产物格式为网页。网页执行模式仅用于现有本机 Agent 的网页任务适配，原提示词要求的 Vite、TypeScript 或单文件 HTML 均保持原文。
